# Plan to Retrieve about.html from a Previous Push

## Objective
Recover the `about.html` file as it existed in the last push (or a specific previous commit) and restore it to the working directory.

## Steps

### 1. Identify the Target Commit
- Use `git log --oneline` to view recent commits.
- Alternatively, use `git reflog` to see recent HEAD movements, including pushes.
- Determine the commit hash where `about.html` existed (likely the commit before it was deleted or modified).
- If unsure, search for commits that touched `about.html`: `git log --follow -- about.html`.

### 2. Verify File Existence in Target Commit
- Run `git ls-tree -r <commit> --name-only | grep about.html` to confirm the file exists in that commit.
- Optionally view the file content: `git show <commit>:about.html`.

### 3. Retrieve the File
- **Option A (Extract to working directory without changing HEAD):**
  ```bash
  git show <commit>:about.html > about.html
  ```
- **Option B (Restore file in working tree via checkout):**
  ```bash
  git checkout <commit> -- about.html
  ```
- If the file path is nested, include the relative path (e.g., `src/about.html`).

### 4. Verify and Commit (Optional)
- Check the restored file content.
- If you want to keep this version, stage and commit:
  ```bash
  git add about.html
  git commit -m "Recover about.html from <commit>"
  ```

### 5. If the File Was Deleted in a Later Commit
- Find the commit just before deletion: `git log --diff-filter=D --summary | grep about.html` or use `git log --about.html`.
- Use the commit hash of the parent of the deletion commit.

## Notes
- Ensure you are on the correct branch where the file existed.
- If the file was only in a remote branch, fetch updates first: `git fetch origin`.
- Replace `<commit>` with the actual commit hash or reference (e.g., `HEAD~1`, `origin/main`).

## Estimated Time
- 5-10 minutes depending on repository size and clarity of commit history.
